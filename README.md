# MOD TOOL
Android modding utility prototype by **Tham Suwannarat**.

## Version 0.1
- Dark blue/purple UI
- Choose game folder using Android Storage Access Framework
- Select IMG and PNG files
- Backup and Save buttons clearly report that the writer is not implemented

**Important:** This prototype does not edit IMG or TXD databases yet.

## Build
Open **Actions > Build MOD TOOL APK > Run workflow**.
Download the **MOD-TOOL-debug-apk** artifact after a successful run.
